## 接受的边界与设备验收

- 外置音轨 HLS 当前采取安全拒绝；本版不承诺已支持音视频合并。
- 无痕仍共享进程默认 WebView profile 的 Cookie/缓存；不写历史与会话不等于 Cookie 隔离。
- GM 原生桥、网页视频 custom-view 全屏，以及按网站申请摄像头/麦克风/定位没有在本轮新增。
- 嗅探仅覆盖带已知扩展名的 GET；不保证 blob、DRM 和无扩展名地址。
- 系统 DownloadManager、Media3 HTTP 和 WebView QUIC 不全部经过应用内 DoH/TCP 入口。
- 没有本地 Android SDK/adb 实测。本地替身测试不能证明真实 WebView 文件选择、SAF 授权、DownloadManager、WorkManager、PiP、CameraX 或媒体解码正常。完整 Gradle 编译、资源链接、lint、R8 和签名以对应提交的 CI 为准，交互及长期资源使用仍待设备验证。
