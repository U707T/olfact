## 1. 这一轮修了什么

rc6 → rc8 共约 50 个提交，分四类。

### 1.1 设置「不再说谎」

| 项 | 结果 |
|---|---|
| 无实现开关 | 删除 19 个（返回不重载、侧滑返回、双击缩放、DNT、语言、日志级别等） |
| 只回显开关 | 接上 6 个真实逻辑：护眼、允许打开应用、画中画、默认倍速、小媒体过滤、第三方 Cookie |
| 下载设置 | 设置页与队列合并为一份 DataStore（`DownloadKeys`），「仅 Wi-Fi / 通知 / 线程 / 并发」真正生效 |
| 即时生效 | 夜间模式、字体缩放、底栏样式、护眼模式改完不重启；Web 类设置改完浏览器回前台自动刷新 |
| 假动作 | 清除缓存/Cookie 接 `PrivacyCleaner` 并回显真实体积；恢复默认设置；设置搜索（含子页索引） |
| 下载目录 | 不再谎报 `/Download/olfact`，显示应用专属目录真实路径 |

### 1.2 断头路

- 网页加载失败：错误页（错误码 + 重试 + 复制网址）。
- AI 未配置：对话框直达供应商页；AI 总结/翻译开关控制入口。
- 广告规则更新：回显「规则已更新 · N 条 / 失败原因」。
- 脚本：支持从 `.user.js` 直链安装，长按删除 + 撤销。
- 备份：恢复后「立即重启应用」，显示上次备份时间。
- 下载：通知点击进详情；前台服务通知；删除/清空前确认；全部暂停/继续。
- 删除：书签/历史/收藏/脚本可撤销；供应商/订阅删除确认。
- 播放页：不再进入即拉起播放器，隐藏不可用的进度条/全屏/PiP 按钮。
- 已下载文件：FileProvider 打开。
- 工具箱：扫一扫、二维码分享、网络日志（之前是死代码）。
- 长按菜单：锚定手指位置的浮层；添加下载：居中对话框（网址/文件名/后缀）。

### 1.3 性能

- 历史 / 书签 / 下载 / 收藏：`RecyclerView`，1000 条不再一次性建 6000 个 View。
- 历史/书签：落盘改后台 + debounce，`onPause` 补写；列表进度 250ms 采样。
- 本地备份：流式写 zip；M3U8：分片流式解密（内存峰值降到并发 × 64 KB）。
- 扫码：720p + 缓冲复用；隧道：固定 32 线程；DoH 停止放 IO。
- `AppLog` 加锁；`LinkExtractor` 正则预编译。

### 1.4 数据与界面

- **修复收藏重启丢失**：`FavoriteStore.init` 之前从未调用；收藏纳入备份（格式 v2，兼容 v1）。
- **修复同名下载覆盖**：目标文件存在时自动加序号。
- 加书签/收藏判重。
- 色板单一来源（app 颜色指向 core `uikit_*`）；对比度达 WCAG AA。
- 首页尺寸对齐原版；下载 tab 绿色下划线；空态统一并居中；列表分隔线。
- 资源只保留 `zh`，不再假装支持英文。

## 2. 仍然没做的

| 项 | 原因 |
|---|---|
| 标签切换复用同一个 WebView surface | 需要 per-tab surface 池 + host 重绑 + LRU 上限，涉及导航栈与 Fragment 生命周期；必须真机回归，建议单独分支 |
| M3U8 合并的 TS→MP4 remux 流式化 | 当前 remux 仍是整文件处理，收益低于风险 |
| 设置页 RecyclerView 化 | 已改为「只更新当前行」，足够；整页 RecyclerView 属锦上添花 |
| 英文资源 | 产品决定只做中文；已移除 `en` 配置 |
