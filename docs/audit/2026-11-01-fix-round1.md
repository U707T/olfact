# 修复记录 · 第 1 批（2026-11-01，rc6 基线）

> 对应三份审计：`2026-11-01-ux-audit.md`（操作逻辑）、`2026-10-31-ui-audit.md`（UI/观感）、
> `2026-10-31-runtime-audit.md`（性能/线程）。
> 本批目标：先消灭「会崩 / 会骗人 / 用户马上能感知」的问题，改动保持可回滚、可单测。

## 0. 本批结论

- **稳定性 P0**：GM 桥跨线程操作 WebView、嗅探缓存并发、历史/书签主线程整表落盘，三处已修。
- **设置可信度**：设置页与下载队列合并为一份 DataStore；18 个无实现开关从界面移除，6 个接上真实逻辑。
- **即时生效**：夜间模式、字体缩放、底栏样式、护眼模式改完立即生效，不再要求重启。
- **断头路**：网页加载失败有错误页（重试/复制网址）；AI 未配置直接跳到供应商页。
- **下载**：Worker 加前台服务；列表 ⋮ 的 4 个占位菜单换成可用的排序/显示时间。
- 验证：`:app:compileDebugKotlin` 与 `testDebugUnitTest` 全绿（本地离线构建）。

## 4. UI / 观感

- **底栏样式**：`BottomBar.configure` 在 `ICON_ONLY` 下把标题胶囊退化为图标槽；纯图标模式不再和胶囊模式渲染一样。
- **底部安全区**：底栏隐藏（设置/列表页）时，`container` 自己加 `bars.bottom` padding，内容不再滚到手势条下面。
- **对比度**（WCAG AA）：
  - 日间 `text_secondary #616161`（白底 6.19:1）、`text_hint #6E6E6E`（5.10:1）
  - 夜间 `text_secondary #A0A0A0`（6.51:1）、`text_hint #8A8A8A`（4.93:1）
  - 新增 `text_accent`（日 `#0C7A44` / 夜 `#2FB877`），替换 6 处把 `brand` 当正文的用法；`brand` 只保留背景/进度/图形用途。
  - core 的 `uikit_*` 同步，`EmptyView` 文字改用 `uikit_text_accent`。

## 5. 断头路

**已闭环（点击后有真实结果或明确下一步）**

- **网页加载失败**：`BrowserSurfaceHost` 新增默认 `onError`；`BrowserClient` 的主文档错误传到 `BrowserFragment`，显示「网页加载失败 + 错误码 + 重试 + 复制网址」，页面开始加载时自动收起。
- **AI 未配置**：toast 换成对话框，「去设置」直接打开 `AiFragment`（不再让用户自己找三层菜单）；`AI_SUMMARY` / `AI_TRANSLATE` 关闭时主菜单与长按菜单不再出现对应入口。
- **扫码非网址**：原来只有「搜索」，现在给「搜索 / 复制 / 取消」三个出口；复制或取消后重置 `handled`，不用退出页面重扫。
- **广告规则更新**：`AdBlockController.refreshAsync` 回报结果，按钮点击后提示「开始更新 → 规则已更新 · N 条 / 失败原因」；添加订阅后自动更新。
- **脚本从网址导入**：`ScriptStore.installFromUrl` 打通到 `ScriptFragment` 的「从网址安装」，支持 GreasyFork 的 `.user.js` 直链，完成后回显脚本名。
- **备份恢复后重启**：恢复成功显示「立即重启应用」，用 `AlarmManager` 预约启动再结束进程，避免 `startActivity` 后立刻退出的竞态；同时显示「上次备份时间」。
- **删除可撤销**：书签/历史删除后 `Snackbar` 提供「撤销」，`BookmarkStore.restore` / `HistoryStore.restore` 原样放回（保留 id/时间）；书签行尾还加了可见的删除图标，不再只能靠长按。
- **播放页不再是假控制条**：移除进入即自动拉起播放器；隐藏不可用的进度条/全屏按钮；只保留「播放 / 嗅探结果 / 下载 / 收藏 / 复制 / 默认倍速」这些真实动作。
- **已下载文件可打开**：新增 `FileProvider`（`file_paths.xml`），下载详情「打开」对 `content://` 直接打开、对本地路径走 FileProvider，失败时提示原因。
- **系统权限管理**：从 toast 改为跳转应用详情设置页。
- **首页语录卡**：首次点按提示「点按语录卡可换一句」。
- **设置改完已打开的页面不刷新**：`RuntimeFlags.reloadPagesOnResume`，改夜间网页/无图/字号/UA/JS 后，浏览器下次回到前台自动 reload。
- **长按菜单文案**：「悬浮嗅探」改为「嗅探结果」，与实际面板一致。

**删除的假动作**

- 「检查更新」只弹「CI 出包后接入」——删掉，等真的接上更新检查再放回。
- 「元素隐藏（cosmetic）」开关没有消费点（元素隐藏实际总是开）——从界面删掉。
- 主菜单「网络日志」与设置页日志入口改为受「开发者模式」控制，普通用户不再看到。

## 5.1 顺带修掉的小项

- **标签上限**：`BrowserSession.open/restore` 接 24 个上限（对齐 web 的 `TabManager`），超出时淘汰最早的非当前标签，会话不再无限膨胀。
- **历史限制即时裁剪**：设置里把「历史记录限制」调小后立即 `trim()`，不用等下一次记录。
- **下载列表进度节流**：`changes` 流按 250ms `sample` 后再 `render()`，避免每秒多次整页 `removeAllViews`。
- **脚本主开关 / GM 桥**：`SCRIPT_ENABLED` 在注入前检查；`SCRIPT_GM_BRIDGE` 关闭时脚本照常执行但不注入 `GM_*` 全局。

## 8. 剩余（按风险排序）

| 项 | 说明 | 风险 |
|---|---|---|
| 标签切换复用同一个 `BrowserFragment`/surface | 需要 per-tab surface 池 + host 重绑 + LRU 上限；必须真机回归 | 高 |
| M3U8 分片流式解密 | `Aes128Decryptor` 目前整段 `ByteArray`，改 `CipherInputStream` 要处理 padding | 中 |
| 长按菜单改锚定浮层 | 需要 `BrowserView` 传出长按坐标 + `PopupWindow` 列表 | 中 |
| 双色板合并 / 英文资源 / 触控目标全面 40dp+ | 纯一致性清理，改动面广但低风险 | 低 |
