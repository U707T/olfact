## 2. 这轮定位到的根因

### 2.1 首页统计卡 / 最近访问空白

`HomeFragment` 用 `statsSignature` / `recentSignature` 两个 **Fragment 字段**做「数据没变就不重建」。
Home 被返回栈保留时，Fragment 实例和字段都在，View 却已销毁重建；`onViewCreated`
看到签名没变就跳过 `buildStats` / `renderRecent`，新 View 里就是空的。

修复：`onViewCreated` 里重置签名并 `refreshHomeData(force = true)`；
`refreshHomeData` 额外把「容器 childCount == 0」也当成需要重建，任何路径都不会留空白卡。

### 2.2 底栏三个入口都进标签页

旧底栏槽位是 `home / action / main(PILL) / tabs(COUNT) / menu`，`action` 在非浏览器页、
`main`、`tabs` 三处都执行 `Nav.toggle(TabsFragment())`；纯图标模式又把 PILL 退化成第二个首页图标。

修复：按原版五槽恢复语义（首页 / 刷新·前进 / 地址胶囊 / 标签数 / 菜单），并补上原版的
4 个布局变体与**全部槽位的长按**。底栏不再自己维护选中态，图标统一 `blackText2`。

### 2.3 切标签把首页/返回栈清掉（「首页 UI 消失」）

`TabsFragment` 选标签走 `Nav.root(BrowserFragment)`：`root` 会 `popBackStack` 清栈再 replace，
首页因此被销毁；同时 `root` 用的是异步 `commit()`，中间态 `Nav.current()` 为 null，
`applyChromeForCurrent` 把底栏设成 GONE —— 看起来就是「首页 UI 消失、底栏没了」。

修复：

- 选标签改走 `Nav.switchToTab()`：先 pop 掉覆盖层，底下是浏览器就 `showTab()` 换绑标签
  （不重建 Fragment，返回栈保留），底下是首页就 `push` 一层浏览器。
- `Nav.root` 改 `commitNow()`，`Nav.pop` 改 `popBackStackImmediate()`，消除「容器空一拍」。
- `MainActivity.setChrome`：`visible=false && barId==null` 且当前没有 Fragment 时直接返回，
  不再把底栏闪成 GONE。

### 2.4 浏览器顶栏不是原版形态

原版没有常驻顶栏，地址与页内查找都是贴在底栏上方的覆盖条。旧实现把地址栏、标签数、
菜单做成网页上方一条，既不是原版，也挤掉网页高度。

修复：`fragment_browser.xml` 重写为「网页铺满 + `addressBar`（52dp，默认 GONE）+
`findBar`（48dp，默认 GONE）」，点底栏胶囊才展开地址条并聚焦，候选向上弹。

## 4. 操作流程 / 焦点

- 底栏胶囊 = 地址/搜索入口：首页聚焦搜索框；浏览器展开地址条并全选；标签页先收起覆盖层再处理。
- 返回优先级（浏览器）：收地址条 → 收页内查找 → 网页后退 → `Nav.pop()`（回首页）。
- 标签页覆盖层：系统返回 = 收起覆盖层；「完成」按钮同样只收起，不额外打开页面。
- 新建标签后自动聚焦地址条（原版新窗口就是空地址），不必再点一次胶囊。
- 首页搜索/最近访问在**当前标签**里导航，且已经在浏览器页时不再叠一层浏览器。

## 5. 需要真机复核

1. 底栏四种变体（标题胶囊 / 纯图标 / 前进后退 / 标签在左）的宽度、圆角、深色配色。
2. 首页统计卡三行与右侧风景图等高（112dp）在不同字体缩放下的表现。
3. 地址条向上弹的候选层位置、点击候选后的焦点/键盘收起。
4. 冷启动外链 / 下载通知 → 返回键是否回到首页。
5. 标签页：新建、关闭当前、关闭全部、恢复上次标签、后台打开的 currentId 是否一致。
6. 首页 → 标签页 → 新建 → 返回 → 再新建，统计卡与最近访问是否持续正常。
7. 底栏五个槽位的长按菜单（尤其胶囊/标签数两个锚定浮层的位置）。

## 6. 仍保留的限制

| 项 | 原因 |
|---|---|
| 标签切换仍会重建 WebView（Fragment 不重建，但 WebView 换页） | 需要 per-tab surface 池 + host 重绑 + LRU；无真机不便引入生命周期问题 |
| M3U8 合并的 TS→MP4 remux 流式化 | 与 UI 无关，维持现状 |
| 设置页 RecyclerView 化 | 当前「只更新当前行」已够用 |
| 「文件管理」只尝试打开系统文件管理器 | 未接 SAF 目录选择器，失败时回退提示下载目录路径 |
