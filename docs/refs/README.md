6. **阅读模式页**（字号/背景/进度条）

## 使用约定

- 比对时**忽略状态栏**（电量/信号那一行）与系统导航条。
- 颜色以原版为准，不套 Material3 默认色；尺寸以 `decode/res/values/dimens.xml` 为准，截图用于校验间距与层级。
- 有争议时以「截图 + layout XML」双证据判断，不靠猜。
